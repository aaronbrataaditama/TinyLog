# TinyLog

A portable, tray-only Windows work logger. The TinyLog mascot icon (a tree stump) sits in the system tray; left-click it to open a
small dark bubble with three controls: a notes box, Start/Stop, and Export to Excel. Each Start/Stop pair
is saved as one session with your notes.

Tray right-click menu: **Start with Windows**, **Export**, **Exit**.

## Build

Requires Visual Studio with the C++ toolchain and the Windows SDK (MSVC x64).

```
tools\build.cmd release
```

The output is `build\release\TinyLog.exe`. The script runs the tests, checks the EXE size (must be under
3,000,000 bytes) and must end with `BUILD+TEST OK (release)`. To audit the imports:

```
powershell -NoProfile -ExecutionPolicy Bypass -File tools\audit.ps1 -Path build\release\TinyLog.exe
```

The icons in `resources\` are generated by `tools\make-icons.ps1`; re-run it only if the design changes.

## Portable use

`TinyLog.exe` is self-contained: copy it anywhere and run it. No installer, no registry entries.

Data files are written beside the EXE:

- `TinyLog.jsonl`: one line per completed session (the log).
- `TinyLog.state`: the in-progress session, present only while recording or while a stop is being finalised.
  If it is unreadable, it is renamed `TinyLog.state.corrupt-*` rather than deleted.

Run it from a folder you can write to. For testing, copy the EXE to a scratch folder first so test data
does not mix with real data.

**Start with Windows** creates a `TinyLog.lnk` shortcut in your Startup folder pointing at the EXE. If you
move the EXE, the checkmark clears; toggle it again from the new location.

## Pin the icon

Windows 11 hides new tray icons by default. To keep the TinyLog icon visible:

Settings > Personalization > Taskbar > Other system tray icons > turn on **TinyLog**.

## Known limitations

- **Clock changes:** durations are computed from the wall clock. If the system time changes during a
  session (manual change, time sync jump, DST edge), the recorded duration reflects that change. See
  Spec §5.7.
- **Durability:** data is written to disk on Start and Stop, not continuously. A crash or power loss can
  lose the most recent unsaved change. See Spec §13.4.
- **Single instance:** a second launch opens the existing bubble instead of starting another copy.
- **Export:** writes an `.xlsx` through the Save dialog; cancelling writes nothing.

## Privacy and system access

TinyLog does not read or write the registry, except for what Windows itself does (for example, the
Startup shortcut). It makes no network connections and runs no background threads or polling timers.
